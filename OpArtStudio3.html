SVG is true vector: the pattern is written as exact filled shapes (even-odd), with distortions traced as fine curves.

How it works

Each layer is a field of thin parallel lines. Its spacing sets the line period; cell size is how many lines make one checker cell. A point is black when it lies in an odd column XOR an odd row. Interference also XORs the thin lines themselves, so fractional cell sizes, unequal spacings and small rotations beat against each other.
